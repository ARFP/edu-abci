# Atelier Logique : Logigrammes

Exercices pour muscler votre **raisonnement déductif**, une compétence essentielle pour le débogage, l'architecture système et la cybersécurité.

## Logigramme, Kesako ?

Un **logigramme** est une énigme logique où vous devez croiser plusieurs catégories d'informations pour trouver l'unique combinaison correcte. Le but est de remplir une **grille de résolution** en utilisant des indices textuels. À la fin, chaque élément d'une catégorie doit être lié à un seul élément des autres catégories.

## Exemple Simple

**Énoncé :** 

Trouvez la couleur préféréer de Jade et Hugo.

*   **Joueurs :** Jade, Hugo.
*   **Couleur préférée :** Rouge, bleu
*   **Indice :** Jade préfère le rouge au bleu.

**Grille de résolution :**

| | Rouge | Bleu |
| :--- | :---: | :---: |
| **Jade** | **O** | **X** |
| **Hugo** | **X** | **O** |

*Analyse : Comme Jade préfère le rouge, elle ne peut pas préférer le bleu ne même temps. Par extension, Hugo préfère le bleu.*

## Les 3 Règles d'Or du Logicien

>
> ### 1. Ne devinez jamais
> Un logigramme ne repose jamais sur la chance. Si vous ne pouvez pas placer de signe, relisez les indices. La solution est toujours cachée dans le croisement de deux informations.
> 
> ### 2. L'indice peut en cacher un autre
> Un indice négatif est aussi précieux qu'un indice positif. "Le DevOps n'est pas le plus jeune" vous donne deux infos : le DevOps n'a pas l'âge le plus petit, *ET* la personne la plus jeune n'est pas DevOps.
> 
> ### 3. Soyez patient avec les "indices relatifs"
> Les indices de type "plus rapide que", "à côté de" ou "après" ne donnent pas de réponse immédiate. Ils servent à éliminer des positions (ex: le "plus rapide" ne peut pas être le dernier).
