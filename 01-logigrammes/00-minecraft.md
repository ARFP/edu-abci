## Exercice : La Session Minecraft

**Objectif :** Retrouver quelle ressource chaque joueur est en train de récolter.

*   **Joueurs :** Steve, Alex, Noob.
*   **Ressources :** Diamant, Fer, Bois.
*   **Indices :**
    1. Celui qui mine du **Diamant** utilise une pioche en obsidienne (ce n'est pas Noob).
    2. Steve est dans une forêt, il ne mine aucun minerai.
    3. Alex a déjà assez de **Fer** dans son inventaire, elle ne cherche donc pas ce matériau.

---

| | Diamant | Fer | Bois |
| :--- | :---: | :---: | :---: |
| **Steve** | | | |
| **Alex** | | | |
| **Noob** | | | |

## Correction : La Session Minecraft

**Raisonnement :**
1. L'indice 2 indique que Steve est dans une forêt et ne mine pas : **Steve récolte du Bois**.
2. L'indice 3 dit qu'Alex ne cherche pas de Fer. Comme Steve a déjà le Bois, **Alex cherche le Diamant**.
3. Par élimination, **Noob récolte le Fer** (ce qui est cohérent avec l'indice 1, car il n'a pas le niveau pour le Diamant).

| | Diamant | Fer | Bois |
| :--- | :---: | :---: | :---: |
| **Steve** | X | X | **O** |
| **Alex** | **O** | X | X |
| **Noob** | X | **O** | X |

**Résultat :**
*   **Steve :** Bois
*   **Alex :** Diamant
*   **Noob :** Fer
