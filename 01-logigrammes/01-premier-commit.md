## Exercice : Le Premier Commit

Retrouver quel développeur utilise quel langage de programmation.

*   **Développeurs :** Hugo, Inès, Jade.
*   **Langages :** Java, PHP, Swift.
*   **Indices :**
    1. Jade travaille sur une application iPhone (elle utilise donc **Swift**).
    2. Hugo n'utilise pas le **Java**.
    3. Inès ne connaît pas le **PHP**.

---

### La Grille (À compléter)

| | Java | PHP | Swift |
| :--- | :---: | :---: | :---: |
| **Hugo** | | | |
| **Inès** | | | |
| **Jade** | | | |

## Correction : Le Premier Commit

**Raisonnement :**
1. On place un **O** pour Jade et Swift. On complète sa ligne et sa colonne avec des **X**.
2. Comme Inès ne fait pas de PHP et que Jade fait déjà du Swift, Inès fait forcément du **Java**.
3. Par déduction, Hugo fait du **PHP**.

| | Java | PHP | Swift |
| :--- | :---: | :---: | :---: |
| **Hugo** | X | **O** | X |
| **Inès** | **O** | X | X |
| **Jade** | X | X | **O** |

**Résultat :**
*   **Hugo :** PHP
*   **Inès :** Java
*   **Jade :** Swift
